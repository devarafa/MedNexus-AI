# MedNexus AI

> An AI-powered medical knowledge, research, and image analysis platform for medical education.

> ⚠️ **Medical disclaimer:** MedNexus AI is intended for **informational and educational purposes only**. It is not a substitute for professional medical consultation, clinical diagnosis, or treatment decisions. AI-generated explanations and experimental model outputs may be incorrect and must not be used for medical decisions.

---

## About the Project

MedNexus AI is a proposed web platform that helps users retrieve, understand, and explore medical information in one place. It combines medical terminology lookup, scientific literature exploration, English and Arabic AI-assisted explanations, general health information, and an **experimental** X-ray analysis module whose feasibility is still being investigated.

The project is developed as part of the **Digital Egypt Pioneers Initiative (DEPI)**.

### Planned Features

| Feature                                                                               | Status                                                           |
| ------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Medical terminology search and dictionary (NCBI MeSH proposed)                        | Planned                                                          |
| Bilingual (English and Arabic) AI-assisted medical explanations (Gemini API proposed) | Planned; explanation quality to be evaluated                     |
| Medical research explorer (PubMed E-utilities proposed)                               | Planned                                                          |
